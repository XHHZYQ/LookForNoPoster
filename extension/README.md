# Look For No Poster Chrome Extension

用于在团队列表页逐行打开“初赛”报名表，查找未提交参赛海报、作品标题为空或作品简介为空的学生，并导出 `.xlsx`。

## 安装

1. 打开 Chrome 扩展程序页面：`chrome://extensions/`
2. 开启“开发者模式”
3. 点击“加载已解压的扩展程序”
4. 选择本目录：`extension`

## 使用

1. 登录目标网站并进入团队列表页。
2. 点击浏览器右上角插件图标。
3. 输入继续执行的页码和行号，点击“开始”。
4. 需要暂停时点击“暂停”。
5. 需要导出当前已采集数据时点击“导出 Excel”。

## 导出字段

所有字段均从报名表页面 DOM 获取：

- 团队名称：报名表 `团队名称：`
- 学生姓名：队员列表第一行，表头 `姓名`
- 学校全称：队员列表第一行，表头 `学校全称`
- 指导教师：报名表 `姓名中文：`

## 缺失判断

任一条件满足即记录：

- `参赛海报：` 后面没有 `预览`
- `作品标题：` 后面的值为空
- `作品简介：` 后面的值为空

## 进度恢复

插件会保存当前页码、当前行、已采集数据和已导出行数。页面刷新或重新登录后，回到团队列表页即可继续执行。
